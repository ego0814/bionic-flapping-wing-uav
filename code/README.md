# 样机 1.0 遥控驱动与扑翼参数调节程序

## 来源

该程序由结题报告“附件 / 代码 1 样机 1.0 遥控驱动与扑翼参数调节程序”提取，共 161 个编号源行。为保留原始资料，除去除文档中的行号外，未修改控制逻辑。

## 运行环境

- Arduino IDE
- 主控板：ESP8285
- 舵机库：Arduino `Servo`
- 接收机：A8S（PPM 输出）
- 舵机：FS-K08 × 2

## 接线与通道

| 功能 | 代码定义 |
| --- | --- |
| PPM 输入 | 数字引脚 6 |
| 左/右舵机 | A0、A1 |
| 通道 1 | 左右差动/转向 |
| 通道 2 | 升降偏置 |
| 通道 3 | 油门、频率、幅度混控 |
| 通道 5 | A0 中位微调 |
| 通道 6 | A1 中位微调 |
| 通道 7 | 三档幅度：约 500/550/600 |
| 通道 8 | 升降倍率：1 或 13 |

## 使用方法

1. 使用 Arduino IDE 打开 `flapping_controller_1_0/flapping_controller_1_0.ino`。
2. 选择与 ESP8285 开发板对应的板卡定义和串口。
3. 确认接收机 PPM 信号接在引脚 6，舵机接在 A0、A1。
4. 拆下翼面或确保机构有安全行程后上电测试。
5. 校准遥控器通道方向、端点以及两侧舵机中位，再进行整机运行。

## 注意

- 代码中的 `delayMicroseconds(ys)` 决定半周期节拍；调整扑翼频率时需同时检查舵机响应、电流和机构负载。
- `delay(1000)` 对应约 1 秒上电等待，报告注释中的文字可能与实际数值不一致，以代码值为准。
- 本项目为实验性样机代码，不包含飞控闭环、失效保护或电池低压保护逻辑，运行前应自行补充安全措施。
