# STEP 交换格式

本目录不重复存放 STEP 文件，以控制 Git 仓库体积。21 个 STEP 文件已拆成 7 个独立 ZIP，作为 v1.0.0 发行版附件发布：

<https://github.com/ego0814/bionic-flapping-wing-uav/releases/tag/v1.0.0>

附件命名：`STEP-models-pack-01.zip` 至 `STEP-models-pack-07.zip`。每个 ZIP 都可以单独解压，不需要合并。

STEP 文件包括机身、翅根、输入杆、约束杆、齿轮、尾翼、腹板和三种厚度的滑箱等零件，适合在其他 CAD 软件中查看或用于加工前检查。每个分卷包含的文件、大小和 SHA-256 见 [`STEP_PACKS.md`](STEP_PACKS.md)。

SolidWorks 原生文件保存在 [`../solidworks/`](../solidworks/)，无需下载 STEP 分卷即可获取完整原生模型。
